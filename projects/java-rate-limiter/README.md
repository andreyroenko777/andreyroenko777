# Token Bucket · Ограничение частоты запросов

Потокобезопасный компонент на Java 21. Ведро с заданной ёмкостью разрешает короткий всплеск нагрузки и пополняется по мере течения монотонного времени. Пополнение и списание токена происходят под одной блокировкой.

```java
var limiter = new TokenBucket(10, 2.0);
var decision = limiter.tryAcquire();
```

`Decision` возвращает разрешение, остаток целых токенов и время ожидания в секундах. Один объект хранит один лимит внутри JVM.

## Проверка

```bash
javac -d out TokenBucket.java TokenBucketTest.java
java -cp out TokenBucketTest
```

Тест управляет часами без sleep и проверяет исчерпание и восстановление лимита. В сценарии со 100 одновременными запросами, замороженным временем и ёмкостью 10 проходят ровно 10.
