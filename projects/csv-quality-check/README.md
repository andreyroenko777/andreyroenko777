# CSV Quality Check

Консольная утилита на Python для проверки CSV перед загрузкой в отчёт или базу данных. Она считает строки с неверным количеством полей, пустые значения по столбцам и повторы ключа. Результат выводится в JSON, поэтому его можно использовать в скриптах.

## Запуск

Требуется Python 3.8 или новее. Установите Python и запустите команду из папки проекта.

```bash
python csv_quality.py example.csv --key order_id
```

В примере 5 записей, одна строка с неверным количеством полей, одно пустое значение в `revenue` и один повтор ключа. Повторы считаются после первого появления каждого ключа. Чтобы проверить составной ключ, укажите `--key` для каждого столбца. Для другого разделителя используйте, например, `--delimiter ";"`.

Утилита читает UTF-8, включая файлы с BOM. Строки с неверным количеством полей исключаются из подсчёта пропусков и повторов. При проверке пропусков и ключей пробелы по краям ячеек игнорируются. Идентификаторы сравниваются как текст, поэтому ведущие нули сохраняются.

| Код выхода | Значение |
| --- | --- |
| `0` | Таблица содержит записи и прошла проверки |
| `1` | Обнаружены проблемы с данными или в таблице только заголовок |
| `2` | Файл невозможно прочитать, CSV синтаксически некорректен или неверно заданы параметры |
