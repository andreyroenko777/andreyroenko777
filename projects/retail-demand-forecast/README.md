# 📈 Retail Demand Forecast

Прогноз количества продаж на следующий день по 12 товарам. Сценарий имитирует сезонность по дням недели, запланированные промоакции и тренд по отдельным товарам. Все 3 360 наблюдений синтетические и генерируются при запуске.

## Как устроен эксперимент

1. Для каждого SKU строятся лаги за 1 и 7 дней и среднее за 28 прошедших дней. День недели и флаг запланированного промо доступны заранее.
2. Последние 56 дней разделены на 28 дней валидации и 28 дней теста. По валидации выбирается размер деревьев, затем модель обучается на всех данных до теста.
3. Тест имитирует последовательный **однодневный** прогноз. Фактические продажи предыдущих дней уже известны к моменту следующего прогноза.
4. Градиентный бустинг сравнивается с продажами того же дня прошлой недели и медианой по SKU, дню недели и промо, рассчитанной на истории до теста.

## Результат на тесте

| Метод | MAE, ед. | WAPE |
|---|---:|---:|
| Продажи неделю назад | 25,02 | 24,76% |
| Историческая медиана с учётом промо | 12,46 | 12,34% |
| Градиентный бустинг | **7,90** | **7,82%** |

Тест содержит 336 прогнозов. WAPE — сумма абсолютных ошибок, делённая на сумму фактических продаж. Результат показывает качество в рамках заданной симуляции. Для реальных данных отдельно понадобятся проверки остатков, пропусков в календаре и изменений промо.

## Запуск

```bash
python -m pip install -r requirements.txt
python forecast.py
```

[Код эксперимента](forecast.py) создаёт `output/predictions.csv` с прогнозами и `output/sku_errors.csv` с MAE по товарам.
