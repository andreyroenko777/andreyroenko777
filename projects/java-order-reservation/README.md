# Order Reservation · Два Java-сервиса

Учебный сервис резервирования товара. Два процесса обмениваются HTTP-запросами. Инвентарь хранится в памяти, поэтому демонстрация запускается с одним JDK.

| Сервис | Порт | Ответственность |
|---|---:|---|
| Orders | 8080 | Принимает запрос, проверяет параметры и вызывает Inventory с тайм-аутом |
| Inventory | 8081 | Проверяет остаток, резервирует товар и сохраняет результат запроса вместе с его ID |

Повтор того же ID и состава заказа возвращает сохранённый ответ. Тот же ID с другим составом даёт HTTP 409. Проверка и изменение остатка выполняются под одной блокировкой. При недоступном Inventory клиент получает HTTP 503 и может повторить запрос с тем же ID.

## Запуск

```bash
javac -d out ReservationDemo.java ReservationTest.java
java -cp out ReservationTest
```

Для ручной демонстрации запусти по одному процессу в двух терминалах:

```bash
java -cp out ReservationDemo inventory
java -cp out ReservationDemo orders
```

```bash
curl -i -X PUT http://127.0.0.1:8080/orders/order-1/book/2
```

Тест проверяет повтор запроса, конфликт ID, недоступность второго сервиса и сценарий, где из десяти одновременных запросов подтверждаются ровно три по доступному остатку. Состояние сбрасывается при перезапуске Inventory.
