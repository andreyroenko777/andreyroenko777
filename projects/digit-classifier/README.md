# 🧠 Digit Classifier

**Задача:** по матрице яркостей 8×8 определить цифру от 0 до 9 и проверить, насколько предсказания устойчивы к шуму.

## Данные и методика

- 1 797 изображений из Digits. Для финальной оценки отложено 25% данных со стратификацией по цифрам.
- Параметры настраиваются по macro-F1 на пяти фолдах. Масштабирование логистической регрессии выполняется внутри `Pipeline`.
- [Обучение](train.py) сохраняет модель и матрицу ошибок. [Инференс](predict.py) загружает модель, проверяет форму и диапазон пикселей и выводит предсказание.

| Модель | Macro-F1, кросс-валидация |
|---|---:|
| Самый частый класс | 0,0182 |
| Логистическая регрессия | 0,9674 |
| SVC с RBF-ядром | **0,9919** |

На отложенной выборке SVC получил **99,11% accuracy** и **0,9911 macro-F1**. Дважды модель приняла восьмёрку за единицу.

## Устойчивость к шуму

К пикселям отложенной выборки добавляется гауссов шум, результат ограничивается исходным диапазоном от 0 до 16. При стандартном отклонении 1, 2 и 4 macro-F1 составил **0,9867**, **0,9799** и **0,9533** соответственно. Эксперимент описывает устойчивость к этому типу искажения на Digits.

## Запуск

```bash
python -m pip install -r requirements.txt
python train.py
python predict.py --example 7
python predict.py --image path/to/image.csv
```

Для своего примера передай CSV из восьми строк по восемь чисел. Артефакты обучения сохраняются в `artifacts/`.
