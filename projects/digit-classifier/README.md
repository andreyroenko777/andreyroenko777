# Распознавание рукописных цифр

Модель определяет цифру от 0 до 9 на изображении размером **8×8 пикселей**. Используется встроенный в scikit-learn датасет Digits из 1 797 изображений.

## Эксперимент

25% данных отложены для финальной оценки. Параметры логистической регрессии и SVC подбираются на остальных данных с пятикратной стратифицированной кросс-валидацией. Масштабирование выполняется внутри `Pipeline`, поэтому параметры преобразования обучаются внутри каждого фолда.

| Модель | Macro-F1 на кросс-валидации |
|---|---:|
| Предсказание самого частого класса | 0,0182 |
| Логистическая регрессия | 0,9674 |
| SVC | **0,9866** |

На отложенной выборке SVC показал **98,22% accuracy** и **0,9821 macro-F1**. Один из наиболее частых типов ошибок — цифра 8, распознанная как 1. Это произошло дважды. Метрики относятся к изображениям Digits размером 8×8.

## Запуск

```bash
python -m pip install scikit-learn==1.8.0
python train.py
```
