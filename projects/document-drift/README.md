# Document Drift

Утилита на Python сравнивает две версии Markdown и показывает, какие разделы изменили, переместили, переименовали, добавили или удалили. Для разделов и изменённых строк отчёт даёт номера строк в обеих версиях. Это удобно при проверке рабочей инструкции, новой редакции учебного плана или личного чек-листа.

Идею подсказал MarkItDown из GitHub Trending. Он приводит разные форматы документов к Markdown, а Document Drift помогает разбирать изменения между двумя Markdown-версиями. [MarkItDown](https://github.com/microsoft/markitdown) · [GitHub Trending по Python](https://github.com/trending/python)

## Запуск

Требуется Python 3.10 или новее. Из папки проекта запустите сравнение двух вымышленных инструкций к учебному симулятору.

```bash
python -X utf8 document_drift.py examples/before.md examples/after.md
```

В отчёте число 12 заменится на 15 в строке 5. Раздел «Диагностика» будет отмечен как перенесённый со строки 21 на строку 17. Отдельно появятся удалённый «Архив» и добавленный «Повтор». Чтобы передать отчёт другому инструменту, добавьте флаг `--json`.

## Как сопоставляются разделы

1. Парсер строит дерево заголовков с `#` вне ограждённых блоков кода. Он хранит собственный текст каждого раздела и номера строк. Вложенные разделы сравниваются отдельно.
2. Сначала алгоритм сопоставляет уникальные пары заголовков и текстов, затем заголовки в уже сопоставленных родительских разделах. Совпадающий текст помогает распознать переименование. Изменённый раздел под другим родителем сопоставляется по уникальному заголовку и сходству текста от 0,65. При нескольких оставшихся кандидатах с одним заголовком отчёт показывает неоднозначность.
3. Перенос между родителями виден напрямую. Для перестановок внутри одного родителя алгоритм сохраняет самую длинную возрастающую подпоследовательность общих разделов. Так вставка строки или нового раздела сама по себе не создаёт ложный перенос.
4. Для сопоставленных разделов сравниваются строки текста и показываются изменённые фрагменты на обеих сторонах.

Поддерживаются заголовки Markdown с `#` и файлы UTF-8, в том числе с BOM. Алгоритм сравнивает структуру и строки текста. При нескольких равноценных порядках отчёт показывает один детерминированный вариант. Сильно переписанный и перенесённый раздел может отобразиться как удаление и добавление.

## Проверки

```bash
python -X utf8 -m unittest -v
```

Тесты проверяют перенос и изменение правила с точными номерами строк, повторяющиеся заголовки, переименование родителя, вставку раздела и разбор блока кода.
