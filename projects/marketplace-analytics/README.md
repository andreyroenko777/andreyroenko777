# Продажи на маркетплейсах

Как меняется выручка после возвратов и в каком канале стоит проверить причины возврата?

Кейс на **1 296 синтетических заказах** Ozon и Wildberries за январь–июнь 2025 года. Один заказ соответствует одной строке. Данные генерируются при запуске с фиксированным seed.

## Результат

| Wildberries | Апрель | Май | Июнь |
|---|---:|---:|---:|
| Заказы | 112 | 120 | 128 |
| Доля возвратов | 8,0% | 21,7% | 25,8% |
| Выручка после возвратов | 289 540 ₽ | 260 796 ₽ | 268 347 ₽ |

В мае количество заказов выросло на 7,1%, а выручка после возвратов снизилась на 9,9%. В реальном отчёте следующим шагом была бы разбивка возвратов по SKU и причинам.

## Расчёт

- [metrics.sql](metrics.sql) группирует заказы по месяцу и каналу. Оконная функция `LAG` берёт выручку прошлого месяца для расчёта динамики.
- [analyze.py](analyze.py) генерирует данные, выполняет SQL в SQLite, сверяет выручку с независимой агрегацией в pandas и выгружает CSV.
- Выручка после возвратов — сумма стоимости невозвращённых заказов. Комиссии, доставка и себестоимость в наборе отсутствуют.

## Запуск

```bash
python -m pip install pandas==2.2.3
python analyze.py
```

Запускать из папки проекта. Результат сохраняется в `marketplace_report.csv`.
