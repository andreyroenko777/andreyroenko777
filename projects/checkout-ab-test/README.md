# 🧪 Checkout A/B Test

Учебный эксперимент по упрощению формы заказа. Гипотеза — сокращение шага с контактными данными увеличит долю пользователей, оплативших заказ. Данные сгенерированы для 12 000 условных участников с фиксированным seed.

## Методика

- Единица рандомизации и анализа — пользователь. Конверсия считается от **всех назначенных** в вариант, включая тех, кто не открыл оформление.
- [SQL](funnel.sql) собирает воронку «открыл оформление → отправил форму → оплатил». Учитываются порядок событий и повторные сообщения об оплате.
- [Python](analyze.py) проверяет уникальность пользователя и монотонность воронки, оценивает разницу в конверсии и строит 95% интервал бутстрэпом внутри каждой группы.

## Результаты симуляции

| Вариант | Назначено | Открыли | Отправили | Оплатили | Конверсия |
|---|---:|---:|---:|---:|---:|
| A | 5 984 | 4 879 | 2 835 | 2 024 | 33,82% |
| B | 6 016 | 4 968 | 3 144 | 2 236 | 37,17% |

Эффект B относительно A составил **+3,34 п. п.**, 95% интервал **от +1,64 до +5,08 п. п.** Наибольший разрыв в воронке возник на шаге отправки формы. Положительный эффект заложен генератором. В реальном эксперименте перед запуском изменения также проверяются качество логирования и защитные метрики, например доля возвратов.

## Запуск

```bash
python -m pip install -r requirements.txt
python analyze.py
```

Сводка сохраняется в `funnel_summary.csv`.
