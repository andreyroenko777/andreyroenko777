## Избранные проекты

### ☕ [Warehouse · Складской учёт](https://github.com/andreyroenko777/Warehouse)

Веб-приложение для склада: от карточки товара до учёта партии, списания и PDF-отчёта. В работе с остатками учитываются сроки годности, а доступ к операциям зависит от роли пользователя.

**Java 21 · Spring Boot · Spring Security · PostgreSQL**

### 📊 [Marketplace Analytics · Аналитика продаж и удержания](projects/marketplace-analytics/README.md)

Воспроизводимый отчёт для двух каналов продаж на 1 296 синтетических заказах. SQL считает выручку за вычетом возвратов, динамику по месяцам и возврат покупателей по когортам. Python сверяет выручку независимым расчётом и выгружает две таблицы.

**Python · pandas · SQLite · CTE · оконные функции**

### 📈 [Retail Demand Forecast · Прогноз спроса по товарам](projects/retail-demand-forecast/README.md)

Прогноз продаж на следующий день по 12 SKU. Сравнение модели с двумя базовыми прогнозами по последним четырём неделям. В учебной симуляции WAPE снизилась с **12,34%** до **7,82%** относительно прогноза по исторической медиане.

**Python · pandas · scikit-learn · временная валидация**

### 🧪 [Checkout A/B Test · Анализ эксперимента](projects/checkout-ab-test/README.md)

Воронка оплаты по журналу событий для 12 000 синтетических пользователей. SQL восстанавливает порядок шагов и учитывает повторные события. Python оценивает разницу в конверсии и доверительный интервал.

**Python · SQLite · SQL · bootstrap**

### 🧠 [Digit Classifier · Обучение, проверка и инференс](projects/digit-classifier/README.md)

Классификация цифр на изображениях 8×8. Сравнение трёх моделей, подбор параметров на кросс-валидации, оценка на отложенной выборке и проверка устойчивости к шуму. Обученную модель можно запустить на своей CSV-матрице.

**Python · NumPy · scikit-learn · joblib**
